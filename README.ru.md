# Motor Town: Cruise Control Resume

Небольшой Lua-мод для [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) для игры **Motor Town: Behind the Wheel**: добавляет **Resume** для штатного круиз-контроля, как на настоящем автомобиле.

Отключил круиз (тормозом и т.п.), сбросил скорость — нажал **F7**: круиз включается и возвращается к скорости, которая была до отключения.

[English version](README.md)

## Как это работает (коротко)

Мод следит за табло круиза и запоминает заданную скорость. По **F7** он нажимает штатные клавиши игры: *включить круиз* (`5`), затем *быстрее / медленнее* (`Page Up` / `Page Down`) — пачками, сверяясь с табло после каждой, пока цель не совпадёт с запомненной. Физика и файлы игры не изменяются. Подробности: [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md).

Нажатия делает маленький PowerShell-помощник (`SendInput`), который жмёт клавиши **только когда окно игры активно**.

## Требования

- Windows, Motor Town (Steam)
- [RE-UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases) (experimental-latest, не zDEV), установленный в `MotorTown\Binaries\Win64`
- Windows PowerShell 5.1 (есть в Windows 10/11)

## Установка

1. Установи UE4SS так, чтобы существовала папка `...\Motor Town\MotorTown\Binaries\Win64\ue4ss\Mods\`.
2. Скопируй папку `CruiseResume` из репозитория в `Mods`:
   `...\Win64\ue4ss\Mods\CruiseResume\`
3. Запусти игру. Помощник стартует сам и закрывается вместе с игрой.

Удаление: удали папку `CruiseResume`.

## Управление

| Клавиша | Действие |
|---------|----------|
| **F7** | Resume: включить круиз и выставить запомненную скорость |
| F9 | Вкл/выкл мод (на время набора в чате) |
| F8 | Статус в `UE4SS.log` |
| F6 | Подробный лог вкл/выкл |

Предполагаются штатные клавиши: включение круиза — `5`, быстрее — `Page Up`, медленнее — `Page Down`. Если у тебя иначе, поменяй `TOGGLE_KEY`, `INC_KEY`, `DEC_KEY` в таблице `CFG` в начале `Scripts/main.lua`. Помощник знает клавиши `1`–`0`, `pgup`, `pgdn`; для других добавь сканкоды в `$keys` в `helper/keyhelper.ps1`.

Прочие параметры `CFG`: `MIN_SAVE_KMH` (минимальная запоминаемая скорость, 15), `BURST` (макс. нажатий за круг, 15), `TAP_MS`, `SETTLE_MS`, `MAX_ROUNDS`.

## Заметки

- Едь на штатном круизе — мод сам запоминает скорость с табло.
- Сними круиз и нажми F7. Если круиз уже включён — ничего не произойдёт.
- Запомненная скорость сбрасывается при смене машины.
- Первое F7 после запуска может только запустить помощника — нажми ещё раз через пару секунд.

## Если не работает

- `ue4ss\UE4SS.log` — строки `[CruiseResume]` (F8 печатает статус).
- `CruiseResume\helper.log` и `helper_stdout.log` — вывод и ошибки помощника.
- Ничего не происходит: окно игры должно быть активным, в `helper.log` должны быть строки `tap ...`, клавиши игры должны совпадать с `CFG`.
- F7/F9 заняты другим модом — поменяй `RESUME_KEY` / `DISABLE_KEY`.

## ⚠️ Предупреждение

Мод использует инъекцию UE4SS и эмуляцию нажатий клавиш. **Проверь правила сервера**, на котором играешь: на некоторых запрещены моды/макросы или есть античит. Используй на свой риск. Проект не связан с разработчиками игры.
